3. Send test Key Pressure events

These buttons simulate Polyphonic Key Pressure (Aftertouch) on MIDI channel 1, note 1, with pressure values 1–4. They do not send MIDI Note On messages.

The role-specific mapping is applied on each display. These are browser test buttons for now; a future MIDI bridge can send the same event object.

Networking note: both pages should be served from a secure context (HTTPS, or localhost for development). QR libraries load from a CDN, so internet access is needed for QR generation in this prototype. WebRTC media/data itself can operate over the local network. If a network blocks direct connectivity, a TURN relay may be needed.
